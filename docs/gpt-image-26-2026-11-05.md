# GPT Image 2.6 support — November 5, 2026

## Sources

- Announcement: https://openai.com/index/introducing-images-2-6/ (November 4, 2026)
- Flare: https://developers.openai.com/api/docs/models/gpt-image-2.6-flare
- Sunburst: https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst
- API guide: https://developers.openai.com/api/docs/guides/image-generation
- Output calculator: https://developers.openai.com/_astro/GptImageTokenCalculator.react.B8NGWY1d.js
- OpenRouter: https://openrouter.ai/openai/gpt-image-2.6-flare

OpenAI positions Flare as the fast model (about 6 s at low quality, 50% faster than before) and Sunburst as the detailed one with more consistent edits at medium and high. These are provider claims, not Banana Browser measurements. Both take the same qualities as 2.5 (low, medium, high, xhigh, max), the same size limits (multiples of 16, up to 3840 per edge, 655,360–8,294,400 pixels, aspect up to 3:1, above 2560×1440 experimental), and 0–3 streamed partial images.

## What changed in the app

- `gpt-image-2.6-flare` and `gpt-image-2.6-sunburst` are selectable with an OpenAI key, with the same sizes, qualities and output formats as 2.5.
- **GPT Image 2.6 Flare is the default** with an OpenAI key, at 1920×1280 low. On OpenRouter, `openai/gpt-image-2.6-flare` replaces 2.5 Flare in the curated set and is the OpenRouter-only default.
- Both 2.6 models are allowed on the ChatGPT plan route (client and relay server). The plan default stays GPT Image 2, the only model verified there.
- 2.5 Flare and Sunburst remain available with an OpenAI key.

The API's new `complexity` setting (low/medium/high, default high), markup-guided edits, SVG output and animated GIFs are not used. The app leaves `complexity` at OpenAI's default; low is meant for small focused edits and could drop text on dense pages.

## Cost

The rates are the same as 2.5: $5/M text input ($1.25 cached), $8/M image input ($2 cached), $30/M image output. Output tokens differ: the official calculator takes 2.5's tokens and multiplies them by 4.2 at low and 3.3 at medium, rounding. High, xhigh and max are unchanged.

| 1920×1280 | low | medium | high | xhigh | max |
|---|---:|---:|---:|---:|---:|
| 2.5 tokens | 197 | 428 | 1,712 | 3,067 | 6,847 |
| 2.6 tokens | 827 | 1,412 | 1,712 | 3,067 | 6,847 |

The default 2.6 page shows about $0.032 on the badge ($0.0075 assumed text input plus $0.0248 output), against $0.013 for 2.5. The OpenRouter badge is about $0.03. Actual response usage still drives session totals.

## Ratings

Not measured yet. 2.6 Flare takes 2.5 Flare's rating (⚡⚡ ★★★ $) and 2.6 Sunburst takes 2.5 Sunburst's (⚡ ★★★★ $). 2.5's speed claims ran slower here (18.0 s measured for Flare), so the speed tier waits for a measurement.

## Verification

All 258 app tests and the build pass. The token estimate matches a replica of the published calculator's function for 80 size and quality combinations, and golden values are in `tests/image25-cost.test.mjs`. No paid 2.6 calls were made: no OpenAI key was available in this environment.
