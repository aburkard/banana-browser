# GPT Image 2.5 support — September 8, 2026

## Current official sources

- Announcement: https://openai.com/index/introducing-chatgpt-images-2-5/
- Flare: https://developers.openai.com/api/docs/models/gpt-image-2.5-flare
- Sunburst: https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst
- API guide: https://developers.openai.com/api/docs/guides/image-generation
- Published output calculator: https://developers.openai.com/_astro/GptImageTokenCalculator.react.yz8GdjDh.js

OpenAI positions Flare as faster everyday generation and reports50% lower latency versus GPT Image2; Sunburst emphasizes precise editing with longer generation times. Those are provider claims, not measured Banana Browser results. Both support image generation/editing, inpainting, low/medium/high/xhigh/max/auto quality, streaming0–3previews and transparency. ChatGPT Sketch/templates/comments are product features, not new Images API request parameters.

## Implementation

Both exact API model IDs are selectable. Flare becomes the direct OpenAI API default; the existing verified GPT Image2 ChatGPT-plan default stays. Five explicit qualities and size presets through3840×2160 are exposed, with above2560×1440 labeled experimental. Low remains the quick-draft default; no claim that it matches higher-quality2.5 output. PNG remains lossless default; JPEG(faster per docs) and WebP use95compression when selected. Output/preview MIME types and edit-upload file extensions follow the actual selected format.

Existing separate click interpretation, red-pointer image, previous image continuity, reference-image caps, history, scroll overlap, moderation:low and0–3preview behavior remain. No extra model call or full conversation history is introduced. Transparency/inpainting are documented capabilities but are not separate UI tools: Banana renders whole opaque webpages and already uses targeted edit instructions with the pointer.

The direct plan request and legacy plan wrapper forward the selected model explicitly. Unsupported plan responses fail without substituting another model. Public API documentation does not verify the private ChatGPT-plan endpoint allowlist; live2.5 plan availability remains unverified. Existing plan controls known to be overridden remain hidden.
