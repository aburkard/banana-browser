## Budget and interpretation

Using locally documented rates (`src/browser.ts`, `docs/pricing.md`), 512px image output is estimated at 747 tokens × $60/M = $0.04482 per call, or $0.13446 for three images. Add $0.50/M input tokens and $3/M text/thinking output tokens. Pricing/model behavior has not been independently reverified here. Charging every allowed output token at the image rate gives $0.36864 across three calls, plus input; this is an estimate, not a provider-enforced dollar cap. Treat the three images as a sub-$1 preflight experiment under the overall $10 app budget, checking returned usage. Missing modality details mean costs can be incomplete.
